# MLops Intelligent Analyzer

## Project Description

MLops Intelligent Analyzer is a full-stack application designed to streamline machine learning workflows with features including:

- User authentication with JWT
- Dataset management and selection
- Asynchronous model training using scikit-learn
- Live training progress updates via WebSockets
- Visualization of training results with charts
- Admin panel for user and training run management
- Responsive React frontend with dark/light mode and animations
- Backend API built with FastAPI and SQLite database
- Containerized development and deployment with Docker and docker-compose
- Continuous Integration workflow with GitHub Actions

---

## Features

- Secure user registration and login
- Admin and regular user roles with permissions
- Upload and select datasets for training
- Start training ML models asynchronously with real-time progress
- View training accuracy and metrics visually
- Admin dashboard for managing users and training runs
- Dark and light UI themes with persistence
- Responsive and accessible UI design

---

## Prerequisites

- Docker (version 20.10+)
- Docker Compose (version 1.29+)
- Node.js (version 18+ recommended for frontend development)
- Python 3.10+ (for backend development without Docker)
